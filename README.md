# Portfolio — Pakasa Givains

Site bilingue (français / anglais) statique — simple à héberger sur GitHub Pages.

Pour lancer localement :
- Ouvrir `index.html` dans un navigateur, ou
- Exécuter un serveur simple : `python -m http.server 8000` puis ouvrir http://localhost:8000

Déploiement recommandé :
- GitHub Pages : activer Pages sur la branche `main` et choisir le dossier `/` (root). Le site sera disponible sur `https://givlikegivains.github.io/portfolio/` environ quelques minutes après l'activation.
- Ou déployer sur Netlify/Vercel en connectant le repo.

Personnalisation :
- Remplace le contenu dans `index.html` (FR) et `en/index.html` (EN) pour ajouter tes projets réels, ton CV, et ta photo.
- Ajoute `CV.pdf` à la racine du repo si tu veux que le lien "Télécharger CV" fonctionne.

Notes :
- J'ai poussé des projets exemples comme placeholders. Dis‑moi si tu veux que j'ajoute tes projets maintenant.
